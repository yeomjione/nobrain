### 2주차

텀프로젝트 1

주제: 시간이 지나 활성화 되는 버튼을 자동으로 클릭해주는 프로그램.

주제선정 이유: 야구, 공연, 교통 등등 생활에서 여러 방면에서 예약을 하게 되는데 이를 도와주는 프로그램

목표 구현 기능: 캡처하듯 구역을 정하고 그 구역의 버튼이 활동을 한다면 자동으로 클릭하도록. (버튼의 색, 시간변경, 특정 조건에서 새로고침 후 클릭 등 사이트 별 이벤트를 조사 후 각각 설정하여 실행하도록)

### 4주차

*변경사항
기존 목표는 이벤트를 감지하고 이벤트가 감지되면 버튼을 "클릭" 해주는 프로그램에서 ai가 매크로 위협이 판단되 큰 틀은 유지하되 클릭이 아닌 알람 형식으로 변경하여 제작
추후 알람 부분에 클릭하는 코드를 넣으면 기존 목표인 이벤트 감지 후 클릭이 가능하지만 아직 개인 역량 부족으로 추후 알람에서 클릭으로 변경

4주차 진행 상황
- 만들고자 하는 프로그램의 프롬포트를 작성하여 Claude.ai를 통해 코드 제작 
- 만들고 불편했던 점을 5주차에 보완 예정

5주차 진행할 내용
- 1차 코드를 바탕으로 불편한 점들을 기록하여 개선 예정
- 예매 사이트 특성상 특정 시간이 될 때 새로고침을 해야 예매가 가능한 사이트도 존재하기에 설정된 시간이 된다면 바로 새로고침 해주는 프로그램을 연결해서 제작 예정

### 5주차

5주차 진행 예정

* UI 변경 및 기존의 알람 기능을 버튼 클릭으로 변경 시도
- 기존 UI가 별로라서 새로 UI변경
- 기존에는 알람 기능이지만 이 기능을 버튼 클릭으로 변경하여 기존 계획 의도였던 클릭 기능을 구현하고자 함.

5주차 진행 상황
- UI 및 기능 변경
UI는 심플하게 변경하고 기존의 알람 기능에서 클릭 기능으로 변경하였음. 테스트 사이트에서 실험으로 프로그램의 기능을 실행하였으며 원하는 결과값이 나왔음.
